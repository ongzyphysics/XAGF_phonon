# Title: Extended Atomistic Green's Function (XAGF)

## Author

Zhun-Yong Ong [(zhunyong.research@gmail.com)](mailto:zhunyong.research@gmail.com)

## Introduction

This is the Matlab/Octave code for the Extended Atomistic Green's Function (XAGF) method.
It is based on my 2015 and 2018 papers on extensions to the traditional Atomistic Green's Function methodology for studying ballistic phonon transport. 

The new methodology enables the calculation of mode-resolved scattering amplitudes and transmission/reflection coefficients in quasi-1D nanostructures such the the intermolecular junction between carbon nanotubes.
It can also be used to compute the scattering cross section associated with a lattice defect.
